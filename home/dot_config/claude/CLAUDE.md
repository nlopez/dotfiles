# Terraform Skills (HashiCorp)

- **terraform-search-import** - Discover and bulk import existing cloud resources into Terraform management
- **terraform-style-guide** - HashiCorp official Terraform HCL style conventions and best practices
- **terraform-test** - Writing and running Terraform tests (.tftest.hcl), mocking, assertions
- **refactor-module** - Transform monolithic Terraform configs into reusable modules
- **terraform-stacks** - Terraform Stacks (.tfcomponent.hcl, .tfdeploy.hcl), multi-region/multi-env infrastructure
- **new-terraform-provider** - Scaffold a new Terraform provider
- **provider-actions** - Implement provider actions using the Plugin Framework
- **provider-docs** - Terraform provider documentation for the Terraform Registry
- **provider-resources** - Implement provider resources and data sources (CRUD, schema, state)
- **provider-test-patterns** - Provider acceptance test patterns using terraform-plugin-testing
- **run-acceptance-tests** - Running provider acceptance tests (TestAcc prefix)

When working on Terraform code, use the relevant skill(s) above via the Skill tool.
